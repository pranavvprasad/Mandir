# Mandir
Parametric OpenSCAD design for a hybrid DIY Mandir featuring 3D-printable lathe-turned pillar sleeves, a stepped Phamsana Shikhara, and hardware flange clearances optimized for a 220 × 220 × 220 mm print volume.

<img src="https://github.com/pranavvprasad/Mandir/blob/main/3dModel.png" alt="3d model" style="width: 50%;">

Parametric Sleeves: Configurable top/bottom flange clearances (flange_top_h, flange_bottom_h) with auto-scaling turned pillar sleeve geometry.

Volume Constrained: Phamsana Shikhara pyramid and structural components sized to fit standard 220 mm × 220 mm × 220 mm 3D printer build volumes.

Integrated Hardware: Corner base feet, multi-tiered Phamsana roof, modular Kalasa finials, and an arched Diya tray.
